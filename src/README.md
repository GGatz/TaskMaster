# Task Tracker

A fullstack personal task-tracking app built with React + Vite (frontend) and Node.js + Express + MariaDB (backend).

## 📁 Structure

- `/client`: Frontend (React + Vite)
- `/server`: Backend API (Express, connects to MariaDB)
